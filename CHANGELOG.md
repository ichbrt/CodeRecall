# Changelog

## 0.1.0-alpha.1

First public preview of the local project-reuse workflow.

### Added

- Git-aware local indexing and JavaScript/TypeScript fingerprints in SQLite.
- Separate similarity, technical/structural compatibility, health, safety and confidence scores with reasons and hard blockers.
- Structured adaptation plans and module discovery that requires review.
- Dry-run by default, exclusive byte-for-byte copying, commit/file provenance and verification records.
- First-class CLI and six scoped MCP tools.
- Automated unit, integration, CLI and MCP tests with three synthetic repositories.
- Runnable demo, agent setup instructions and a benchmark protocol without unmeasured savings claims.
- MIT licensing.

### Known boundaries

- Feature extraction is heuristic and supports JavaScript/TypeScript structure only.
- Modules are discovered, not automatically assembled. A coding agent or developer implements adaptations.
- Verification executes an explicitly trusted command outside a sandbox.
- Fixture success does not prove production readiness or measured AI token/cost savings.
- The alpha data format and CLI may change before a stable release.
